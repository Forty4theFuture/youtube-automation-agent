## 5. Findings (c) — ranked

### BROKEN — core promise does not work
- **B1. Publishing upload is fake.** `publishing-scheduling-agent.js` `getVideoStream()` (L154-162) returns `JSON.stringify({message:'Video stream would be provided here', …})` instead of a file stream ("For now, we'll simulate it"). `videos.insert` therefore never uploads a real video. The headline "auto-publish to YouTube" is non-functional. *(upstream)*
- **B2. Media is simulated by default.** Without OpenAI/Replicate keys **and** ffmpeg + a Playwright browser, TTS/visuals/video write `.info`/`.assembly.json` placeholders. All 52 `data/` artifacts are placeholders; no real `.mp4/.mp3/.jpg` exist. So even if B1 were fixed there is nothing real to upload. *(upstream; fork made simulation degrade cleanly but did not add a real path)*
- **B3. Dead npm scripts.** `db:init`→`database/init.js`, `workflow:daily`/`workflow:weekly`→`workflows/*` — all referenced files are **absent**; the commands fail immediately. *(upstream)*
- **B4. MCP is manifest-only.** `mcp/content-strategy-agent.mcp.json` points at `agents/content-strategy-agent-mcp.js` which does not exist; no MCP SDK dependency. *(upstream)*

### RISKY — runs but produces wrong/unsafe results or silently misconfigures
- **R1. Fabricated analytics.** `analytics-optimization-agent.js` `getSimulatedAnalytics()`/`getSimulatedDemographics()` return `Math.random()` views/CTR/engagement on any API error; `content-strategy predictViews()` also uses `Math.random`. These feed the weekly optimization loop and the dashboard — invented numbers presented as data. *(upstream)*
- **R2. Media credentials never reach the engine.** `production-management-agent.js:13` passes the **CredentialManager instance** to `new AIVideoGenerator(credentials)`, but `ai-video-generator.js` reads `credentials.openai?.apiKey` etc. — the parsed file creds live under `credentials.credentials.openai`. So OpenAI/Replicate/ElevenLabs keys saved via the wizard into `config/credentials.json` are ignored; only `.env` values work. Silent. *(attribution: file modified by fork; line may be inherited — open question)*
- **R3. Azure TTS key-name mismatch.** Wizard saves `credentials.azureSpeech.subscriptionKey/.region` (`credential-manager.js:247`); engine reads `credentials.azure?.speechKey/.speechRegion` (`ai-video-generator.js:40-41`). Wizard-configured Azure voice is never used. *(upstream)*
- **R4. Generic content + YouTube-policy exposure.** No niche/voice/originality definition. Strategy fallback angles ("X: What Nobody Is Telling You"), script templates, and thumbnails ("YOU WON'T BELIEVE #1", "MUST WATCH") default to canned clickbait. Daily automated, templated uploads risk YouTube's inauthentic/repetitious-content & spam policies; no automation disclosure; `.env.example` defaults `DEFAULT_PRIVACY_STATUS=public`. *(upstream)*
- **R5. Four overlapping auth implementations.** Wired: `credential-manager` flow. Orphaned/dead: `authenticate.js` (stub — prints URL, never exchanges), `oauth-server.js` (:8080), `simple-auth.js` (deprecated `oob`), `modern-auth.js` (random loopback; hardcodes channel "Ethereal Dreamscript"). Different redirect strategies invite the exact `redirect_uri_mismatch` class of error. *(upstream)*

### COSMETIC / HYGIENE
- **C1. Gemini service is dead code** — `utils/gemini-service.js` unused by any agent (only `test-gemini.js`). *(fork — leftover from Claude migration)*
- **C2. Duplicate thumbnail systems** — Sharp agent vs DALL·E path; the Sharp thumbnail is largely overwritten downstream. *(upstream)*
- **C3. Config documentation drift** — read-but-undocumented: `REPLICATE_API_KEY`, `ELEVENLABS_*`, `AZURE_SPEECH_*`, `WEBSITE_URL`, `SOCIAL_LINKS`, `BUSINESS_EMAIL`, `COMPETITOR_CHANNELS`; documented-but-unused: `TTS_VOICE`, `JWT_SECRET`, `AUTO_*`, image vars, rate-limit vars; `credentials.example.json` omits `claude/anthropic/gemini/replicate/elevenLabs/azure`. *(mixed)*
- **C4. `/generate` `style`/`length` params accepted but unused.** *(upstream)*
- **C5. README "Success Stories" (50K subs, $5K/mo) are fabricated marketing** inherited from upstream — treat as data, not truth. *(upstream)*

### Drift (docs vs code)
README/`ai-video-generator` imply DALL·E thumbnails, real video, and auto-publishing; the wired pipeline uses Sharp thumbnails, simulates media by default, and cannot really upload. MCP and `workflows/*` are advertised (manifest / npm scripts) but absent.

## 6. Fix plan (d) — prioritized, smallest honest end-to-end first

**Target for "runs end-to-end" (dry-run, per boundaries):** generate → real script/SEO/thumbnail → real local `.mp4` → package marked *ready/draft*. **No real upload.**

**P0 — make it honest and unbreak the surface**
1. **R2 + R3 (creds wiring):** pass `credentials.credentials` to `AIVideoGenerator`; align Azure key names. One-line fixes; unlock wizard-configured media keys. *(low risk)*
2. **B1 (publishing honesty):** stop faking upload success. Either implement a real read-stream upload from a real file, or hard-fail/clearly mark "draft — no real video" when the asset is a placeholder. Given dry-run boundary, prefer draft-gating over enabling real upload.
3. **B3/B4 (dead surface):** remove or implement `db:init`, `workflow:daily/weekly`, and the MCP manifest so nothing advertises capability it lacks.

**P1 — safety & channel fit**
4. **R1 (analytics honesty):** never feed `Math.random` into optimization/dashboard; return `null`/"unavailable" and label simulated data explicitly.
5. **R4 (niche/voice + policy):** add a channel voice/niche config; rewrite strategy & script prompts (see §7) with voice, output contract, failure branch, and a never-list; default `DEFAULT_PRIVACY_STATUS=unlisted`; add automation-disclosure guidance.

**P2 — hygiene**
6. **R5:** keep `credential-manager`; delete/park `authenticate.js`, `oauth-server.js`, `simple-auth.js`, `modern-auth.js`.
7. **C1:** remove or formally re-wire `gemini-service.js`. **C2:** pick one thumbnail path. **C3:** sync `.env.example` + `credentials.example.json` with actual reads. **C4/C5:** wire or drop `/generate` params; mark README stories as illustrative.
